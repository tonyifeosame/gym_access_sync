The cloud API server status above is checked live by pinging the GET /stats endpoint.

F22 terminal status is not yet available. The backend currently has no heartbeat / device-status endpoint, so the portal cannot report whether the fingerprint terminal is online.

To enable this, add a device heartbeat to the C++ server (e.g. the terminal periodically calls POST /device/heartbeat, and the portal reads GET /device/status). Let your developer know and this card will light up automatically.
