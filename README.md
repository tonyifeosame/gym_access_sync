Overview

A C++-based gym access control system with a web-based admin portal, SQLite local database, offline synchronization, and cloud-ready architecture.

The system is designed to work with biometric access control devices (such as the ZKTeco F22) and provides secure member management, enrollment workflows, access logging, and synchronization between local terminals and a cloud server.

Features
Member registration
Member management (CRUD)
Dashboard with statistics
Fingerprint enrollment workflow
Access control validation
Access logging
Offline-first SQLite database
Periodic synchronization
REST API for external integrations
Bootstrap web admin portal
API key authentication
Thread-safe database access
Unit and integration tests
